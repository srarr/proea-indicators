# Security

These are TradingView indicator scripts: they run inside TradingView's sandbox, read only chart data, and have no
network access, accounts or secrets.

If you find something in this repository that could harm a user, report it privately through
[GitHub's private vulnerability reporting](https://github.com/srarr/proea-indicators/security/advisories/new) or the
[ProEA contact page](https://proea.app/en/contact). Please don't open a public issue for it. Two examples are a script
that could mislead by design, or a link that leads somewhere unsafe.
